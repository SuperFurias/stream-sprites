## What's New

- **WebM Video Support**: Animated skins now support .webm video files alongside GIFs
- **Automatic Detection**: .webm files in assets/skins/ are automatically detected
- **Dashboard Preview**: WebM files display as playing videos in the skins tab
- **Overlay Rendering**: WebM videos render with autoplay, loop, and mute in the overlay

### Technical Changes
- Extended skin detection to include .webm extension with isWebm flag
- Renamed gifRenderer to ^GnimatedMediaRenderer to better reflect its capabilities
- Updated animatedMediaRenderer to handle both GIF images and WebM videos
- Added video element creation with proper attributes (autoplay, loop, muted, playsInline)
- Updated skin loading to skip preloading for video files
- Fixed skin change detection using data attributes to avoid URL comparison bugs
- Updated overlay CSS to style video elements correctly
- WebM videos now use object-fit: fill and explicit dimensions for precise control

### Fixes
- Fixed !sit command for WebM skins: now only height scales to 0.75, width remains constant
- Removed unwanted fallback circle rendering behind WebM videos

### How to Use
1. Place .webm video files in ^Gssets/skins/ folder
2. Restart the server or refresh the dashboard
3. The videos will appear in the skins list and can be assigned to users
4. Videos will play automatically in the overlay when assigned

### Notes
- WebM videos should be short, looped animations for best performance
- Videos are muted by default (browser autoplay requirement)
- Recommended size: similar to your existing sprite dimensions
