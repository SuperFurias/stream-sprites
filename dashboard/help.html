📝 Chat Commands

Users can type these commands in Twitch chat:

  • !jump - Make avatar jump
  • !sit - Sit down (reduces height to 75%)
  • !unsit - Stand up (restores full height)
  • !boom - Explode all avatars
  • !skin - Change your avatar's skin (must own it)
  • !skins - Show all available skins
  • !spawn [quantity] [skinId] [username] - Broadcaster/Mods: spawn sprites with optional quantity, skin, and name (random if omitted)
